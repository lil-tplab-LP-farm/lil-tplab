文字数カウント(改行・空白・バイト数・原稿用紙換算)

下の入力欄に文章を貼ると、文字数(全部・空白を除く・改行を除く)、行数、UTF-8のバイト数、原稿用紙(400字詰め)に直した枚数が出ます。数えるのはこのページの中だけで、貼った文章はどこにも送られません。

数える

使い方

  1. 入力欄に、数えたい文章を貼り付けるか、直接入力します。入力するたびに結果が更新されます。
  2. 「文字数(全部)」は、スペースも改行も1文字として数えた数です。「空白を除く」は、スペース(半角・全角)・タブ・改行をすべて除いた数、「改行を除く」は、改行だけを除いた数です。
  3. 原稿用紙の換算は、2通り表示します。目安として使ってください。

「1文字」の数え方と、絵文字・結合文字の注意

この道具は、文字列を JavaScript の Array.from で1つずつに分けた数(Unicodeのコードポイントの数)を「1文字」として数えています。多くの日本語の文字・英数字・記号は、これで見た目どおりに数えられます。

ただし、次のようなものは、見た目は1文字でも、2以上に数えられます。

  • 家族・職業などの合成絵文字(例:👨‍👩‍👧 は、人の絵文字3つを見えない結合用の文字でつないだもので、5と数えられます)
  • 肌の色を変えた絵文字、国旗(国旗は2つの記号の組み合わせです)
  • 結合文字(例:「e」の後に「´」を結合させた「é」は2と数えられます。1文字で書かれた「é」は1です)
  • 目に見えない文字(ゼロ幅スペースなど)は、見えなくても1文字として数えられます

そのため、他のソフトやサービスの文字数とずれることがあります。数え方はサービスごとに違うので、文字数の制限があるものに投稿・応募する時は、そのサービス自身の表示で最終確認してください。この道具は、各サービスの文字数の上限は載せていません。

バイト数について

バイト数は、文字をUTF-8で保存した時の大きさです。半角の英数字は1バイト、ひらがな・漢字などの日本語の多くは3バイト、絵文字の多くは4バイトです。ファイルサイズやデータベースの文字数制限の目安に使えますが、文字コードがUTF-8以外(Shift_JISなど)の時は、バイト数が変わります。

原稿用紙の換算について

  • 単純換算:改行を除いた文字数 ÷ 400 です(400字詰め=20字×20行)。
  • 行頭から書く場合:改行で区切った段落ごとに、行の先頭から書き始め、空行も1行使うものとして、20字で折り返した行数を数え、20行で1枚とします。

どちらも簡易な計算です。実際の原稿用紙では、句読点や閉じかっこが行頭に来ない決まり(禁則処理)や、段落の字下げなどがあるため、枚数が変わることがあります。

よくある間違い

  • 「文字数」と「バイト数」を混同する:日本語は1文字が複数バイトです。文字数の制限なのか、バイト数の制限なのかを確認します。
  • スペースや改行を含めるかを確認しない:提出先によって、空白や改行を数える・数えないが違います。
  • 見た目の文字数と一致すると思い込む:絵文字や結合文字は、上のとおり数えられ方が違います。
  • 改行コードの違い:Windowsの改行(2文字分)も、この道具は1つの改行として扱います。
