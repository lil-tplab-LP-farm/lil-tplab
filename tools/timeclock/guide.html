1これは何?

出勤と退勤の時間を、ボタンを押すだけで記録する道具です。美容師がつくった打刻です。3つの約束があります。

🕐
時間だけ測ります。
お給料の計算や、残業の判断はしません。
🔒
記録はこの端末の中だけ。
どこにも送りません。インターネットにも出ません。
🎁
10人まで無料です。
使えるスタッフは、休んでいない人で10人までです。

2はじめの準備

最初に1回だけ、やります。

  1. URLをブックマークします。
    いつも同じURL(アドレス)で開いてください。記録は「そのURL」の中に入ります。URLが変わると、別の記録になって、消えたように見えます。
  2. iPhone・iPadは「ホーム画面に追加」します。
    Safari(アイフォンの標準のブラウザ=ネットを見るアプリ)は、長く開かないと記録を消すことがあります。ホーム画面に追加しておくと安心です。
  3. 下の方の 管理画面 を押して、暗証番号を決めます。
    数字4桁を、2つの欄に同じように入れます。これは、まちがって管理画面を開かないためのものです。強い鍵ではありません。
  4. スタッフを登録します。
    管理画面の「スタッフ」で、名前を入れて 追加 を押します。
💡 同じ端末で、同じブラウザを使ってください。ブラウザが変わると、別の記録になります。

3毎日の打刻

ポイントは「先にボタン、あとで名前」です。

  1. まず 出勤 か 退勤 を押します。
  2. 押した時刻が、大きく画面に止まります。
  3. 「誰ですか?」と出るので、自分の名前を選びます。
  4. 「◯◯さん 出勤」と出たら、記録できました。🎉

記録される時刻は、ボタンを押した瞬間の時刻です。名前を選ぶのが少し遅くなっても大丈夫です。

💡 名前を選ばないまま30秒たつと、その分は捨てられます。もう一度ボタンから押してください。

出勤を押した時は「いま出勤していない人」、退勤を押した時は「いま出勤中の人」、休憩を押した時は「出勤中で休憩中でない人」だけが出ます。

休憩のときも同じです。

  1. 休憩に入る時は 休憩 を押して、自分の名前を選びます。
  2. 休憩から戻ったら 戻り を押して、自分の名前を選びます。(これで勤務にもどります。戻り の名前の候補は、休憩中の人だけです)
  3. 休憩中のまま 退勤 を押した時は、退勤の時刻で休憩も終わったことになります。(勤務表の備考に「休憩戻りなし→退勤で終了」と出ます)

4まちがえた時

  • 押してすぐ気づいた時(10秒以内)
    画面の下に「間違えた?」と出ます。取り消す を押してください。10秒は、名前を選んだ時から数えます。
  • 他の人の分が残っていた時
    ボタンを押したら、自分より前に押された分が残っていることがあります。「これは◯秒前に押された分です」と出たら、自分の分を押し直す を押して、あらためて自分で押してください。
  • あとから直したい時
    管理画面の 打刻の修正 で、時刻を直せます。直した理由も入れます。直したあとも、元の時刻は記録に残ります。
📝 取り消しも修正も、記録には残ります。あとで見返せるので、安心して使ってください。

5退勤を押し忘れた時

あわてなくて大丈夫です。2つのやり方があります。

  • 気づいたその日に: 管理画面の 打刻の修正 →「打刻を追加(押し忘れ)」で、本当の退勤時刻と理由を入れて足します。「手入力」として記録に残ります。
  • 次の日に気づかないまま出勤を押した時: 出勤中のまま12時間たった人は、出勤を押した時の画面に「前回の退勤が未入力の人」として出ます。選ぶと、前回の退勤は空のまま、今日の出勤を記録します。前回の分は、あとで管理画面から足せます。

足していない間、月の勤務表の備考には「未退勤」と出ます。

6月末のこと

1か月の勤務表を、CSV(エクセルで開ける表のファイル)で保存できます。

  1. 管理画面を開いて CSV を選びます。
  2. 月を選びます。
  3. 月の勤務表をCSVで保存 を押します。

文字化けしないで、そのままエクセルで開けます。「打刻の生記録」を保存すると、取り消しや修正も含めた記録がぜんぶ見られます。

勤務表には、「勤務時間」のほかに 休憩入り・休憩戻り(休憩に入った時刻と戻った時刻。休憩が何回かある時は「12:00 / 15:10」のように1つの欄に並べます)、休憩(分) と 実働(時:分)・実働(分) の列があります。休憩は、1回の勤務で何回あっても合計します。実働は「勤務時間 − 休憩の合計」です。休憩の時間を測って並べるだけで、休憩が足りているかなどの判断はしません。

🌙 夜をまたぐお仕事も大丈夫。0時をこえた勤務は「出勤した日」の行に1行で入ります。月末の夜(10/31の22時〜11/1の5時など)や大みそかも、出勤した月のCSVに入ります。退勤の欄には日付もつきます。

7月に1回のバックアップ

記録はこの端末の中だけにあります。端末をこわしたり、ブラウザのデータを消したりすると、記録も消えます。だから月に1回、コピーを取っておきましょう。

バックアップのしかた

  1. 管理画面の バックアップ を開きます。
  2. 全データをバックアップ(JSON) を押します。
  3. できたファイルを、大事に取っておきます(別の場所にもコピーしておくと、もっと安心です)。
📱 iPhone・iPadでは、ファイルは「ファイル」アプリの「ダウンロード」に入ります。ファイル名は「打刻バックアップ_日付.json」です。
💻 パソコンでは「ダウンロード」フォルダに入ります。

復元のしかた(コピーから元にもどす)

  1. 管理画面の バックアップ を開きます。
  2. ファイルを選んで 復元する を押します。
  3. 確認が出たら、よく読んで進みます。
⚠️ 復元すると、いまの記録はバックアップの内容に置きかわります。置きかえる前に、いまの分が自動でファイルに保存されます。そのファイルは消さずに残してください。

暗証番号は、復元しても「いまの番号」のままです。

8暗証番号を忘れた時

だいじょうぶ。記録は消えません。

  1. 管理画面を開いて、番号の入力画面で 番号を忘れた を押します。
  2. 確認の欄に「作り直す」と打ちます。
  3. 新しい番号(数字4桁)を、2回入れます。
  4. 作り直す を押します。
  5. 「作り直しました」と出たら、新しい番号で開き直します。

スタッフも打刻の記録も、そのまま残ります。

📝 作り直した日時は、記録に残ります。管理画面の上に、30日のあいだ「◯月◯日 ◯:◯◯ に暗証番号を作り直しました」と出ます。

9よくある質問

記録が消えた?

たいていは、別のURLや別のブラウザで開いているだけです。記録は「その端末・そのブラウザ・そのURL」ごとに別になっています。いつものURLとブラウザで開き直してみてください。それでも無い時は、バックアップから復元できます。

別の端末でも見たい

端末をまたいで自動でそろえることは、今はできません。見たい時は、バックアップのファイルを作って、もう一方の端末で復元してください。同時に両方で打刻すると、別々の記録になるのでご注意ください。

プライベートブラウズ(シークレットモード)でも使える?

使わないでください。画面は動きますが、閉じると記録がぜんぶ消えます。

タブはいくつまで?

1つだけ開いてください。2つ開くと、片方の表示が古くなることがあります。

休み明けに「端末の時計を確認してください」と出るのはなぜ?

前の打刻から3日以上あとに押すと、「時計がずれていませんか?」と聞きます。休み明けなら、そのまま記録して大丈夫です。同じ日は、2回目から出ません。(前の打刻より前の時刻になる時も、同じ確認が出ます。)

11人以上は使える?

今は10人までです。お休みしている人を「休止」にすると、数に入りません。

記録が残っているか心配

画面の上に「保存テスト」の結果と「バックアップ最終日」が出ています。保存テストが赤く出たら、別のブラウザで開き直してください。
